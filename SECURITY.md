# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The RepoPulse AI team takes software security seriously. If you discover a vulnerability or potential exploit, please do **not** open a public GitHub issue.

Instead, please send an encrypted or direct report to the lead maintainer:
- **Email**: `dhanwinn15@gmail.com`
- **Subject**: `[SECURITY] RepoPulse AI Vulnerability Report`

Please include:
1. Description of the vulnerability and attack vector.
2. Minimal reproduction steps or proof-of-concept diff.
3. Impact assessment.

We commit to acknowledging your report within 48 hours and issuing an advisory patch within 7 days.
