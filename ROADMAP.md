# 🗺️ RepoPulse AI Product & Engineering Roadmap

This roadmap outlines the planned technical milestones for RepoPulse AI.
Feedback and proposals are actively solicited through [RFC Issues](https://github.com/miriyaladhanwinn/repo-pulse-ai/issues).

---

## 📍 Phase 1: Core Foundation (Completed - v1.0.0)
- [x] Unified diff parsing & hunk extraction without external diff utilities.
- [x] AST symbol decomposition for TypeScript, JavaScript, and Python.
- [x] Token budget optimizer with bounded prompt chunk partitioning.
- [x] Native Model Context Protocol (MCP) stdio server implementation.
- [x] CLI maintainer harness (`npx repo-pulse`).
- [x] Zero-dependency issue classifier (P0-P3) and `node:test` reproducer engine.

---

## 📍 Phase 2: Titan Gateway & Studio (Completed - v2.0.0)
- [x] Universal Multi-Model Router (OpenAI, Anthropic, Gemini, DeepSeek, Groq, Mistral, OpenRouter, Ollama).
- [x] Deterministic offline fallback heuristic engine.
- [x] Assistant Matrix with 12 specialized engineering personas.
- [x] Hybrid BM25 Knowledge Vault with tag filtering and JSON backup.
- [x] Apple Developer-grade Liquid Glass Studio on `http://localhost:3000` with 3D canvas graph.
- [x] In-browser AST Code Sandbox & dynamic sink linter.

---

## 📍 Phase 3: Distributed Multi-Repo Intelligence (Q4 2026)
- [ ] **Cross-Repository Symbol Graph**: Persistent SQLite/DuckDB index tracing symbol dependencies across microservice repositories.
- [ ] **WebAssembly Bytecode Tokenizer**: Zero-overhead token count estimation compiled from Rust (`tiktoken-rs` / `tokenizers`) to WebAssembly.
- [ ] **Bi-directional Cherry Studio Plugin**: Official desktop plugin package for seamless installation inside Cherry Studio.
- [ ] **Real-time SSE Streaming**: Server-Sent Events transport for word-by-word streaming in the Web Studio and MCP SSE endpoints.
- [ ] **Automated Benchmark Matrix**: Continuous regression tracking measuring AST slicer throughput against Linux kernel patches.

---

## 📍 Phase 4: Autonomous Maintainer Agents (Q1 2027)
- [ ] **Self-Healing Pull Requests**: Autonomous generation of non-breaking mitigation patches for flagged security vulnerabilities.
- [ ] **Multi-Agent Consensus Swarm**: Dynamic peer-review protocol where Maintainer Lead, CVE Auditor, and Runtime SRE debate review comments before posting.
